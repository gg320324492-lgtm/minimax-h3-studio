## 八、复验协议（每条都抓到过真问题）

1. **变异测试** —— 把修复改回旧实现，确认对应测试转红。**守卫的价值不在通过，在能失败。**
   **并且必须区分「变异存活」与「变异不是有效变异」**（P10 的 11 个变异里前 6 个是后者；
   方向性无效的例子：`FREEZE_DIFF` 只选哪些像素，判据是 `changed == 0`）。
2. **确定性构造原缺陷场景** —— 把最初暴露问题的输入原样搭出来。
3. **全历史扫描** —— `git log --all --diff-filter=A -- <路径>` 查敏感文件是否曾入库。
4. **从仓库外跑测试** —— `cd /tmp && python -m pytest <repo>/tests/ -q`。
5. **像素量化，不靠目检** —— 两两距离分布、bbox、逐像素 diff、backdrop 采样。
6. **交叉验证** —— 同一对象两个条件下度量应一致；mp4 抽帧 vs 新渲只差编码噪声。
   **注意 PNG 无损时那个 mp4 地板不适用**（本轮实测 0.0000%）。
7. **集合差** —— 磁盘 glob vs manifest；schema 字段 vs 实际读取点；
   **以及最有用的一条：schema 声明的字段 vs `git grep` 的读取点数**（P11 因此找到 18 个惰性字段）。
8. **时间线核对** —— 报告 `stat` 时间戳 vs 提交时间。
