## 一、指挥窗口已实测的事实（本指令建立在此之上，不是引述）

### 1. 当前刻度是斐波那契阶梯，不是随手堆的

`studio/src/templates/finance-showcase/design/tokens.ts:82`：

```ts
export const SPACE = {xs: 8, sm: 16, md: 24, lg: 40, xl: 64, xxl: 104, hero: 168} as const;
```

指挥窗口实算比值：`8 : 16 : 24 : 40 : 64 : 104 : 168` = `1 : 2 : 3 : 5 : 8 : 13 : 21`，
即 **`8 × 斐波那契数列`**（Fibonacci 1,2,3,5,8,13,21）。

**这是一条有原则的阶梯。** 账本要求的"4 的倍数"会把它换成等差序列——
比例关系 1:2:3:5:8:13:21 会消失。这不是"更规范"，这是**换成另一条原则**。
