## 二、验证协议（不达标不算完成）

### 1. 变异测试是硬要求

对本守卫做变异，**每个变异都必须让至少一条测试转红**。逐条记录结果。

必须包含的变异：

|---|---|

| 让 `diff_locked` 无条件返回 `[]` | 红 |
| 把双向不变量破坏（例如第二趟 `emit` 删掉） | 红 |
| 把第 4 条的"零消费方"断言删掉 | 红（自我检查：守卫必须能感知自己被削弱） |

### 2. 「变异存活」≠「变异有效」

若某个变异存活，先判定它是**真漏洞**还是**无效变异**（方向性上不可能改变行为）。
两种都要在 commit message 里写明理由。**不要为了杀掉无效变异去造 contrived 输入。**

### 3. 已知会咬人的地方（本项目实测过的坑，务必避开）

- **守卫断言"某个词出现在文本里"会被自己骗过去。** 本项目已发生 **3 次**：
  ① 断言 `'mkdtemp' in source`，结果匹配到了**解释该 bug 的注释**；
  ② 断言文件含 `rmSync`，结果被 `still.mjs` 里为 `--clean` 预先存在的调用满足；
  ③ 断言理由含 `chart_geometry` / `threshold` 两个**词**，结果把整句说法删掉后仍通过。
  → **断言要落在行为上，不要落在文本存在性上。**
- **阈值必须落在信号内，不是信号之上。** `inkFaint` 亮度约 **96**，背景渐变 10–40。
  用阈值 120 会让所有内容"逐像素相同"。
- **先证明被测对象存在，再测量。** 本项目测过一次 150 帧场景的**帧 120**（80% 处、
  生命周期 `exit` 阶段、图表已退场），测出来的"墨迹"全是背景噪声。
- **"最小间隔"这类判据会在关键时反转**：标签融合时段数减少、间隔反而变大。
  （P10 审计早就记录过这个陷阱）
- **写长文本一律在字节层操作**（`read_bytes` + 精确匹配 + 写回），
  写完逐项验 CRLF / 裸 LF 计数。`docs/*.md` 是 CRLF 文件。
  另：heredoc 里 `\\b` 会被 shell 变成退格符（`\x08`）——用 `bytes([92])` 显式构造。
