## 一、两条判定与它们的判据（**可推翻**）

### B-2：末帧近黑 —— 判为 **`visual_qa` 误报，不是片子缺陷**

**判据**：一个收尾方式**是不是缺陷，取决于它是不是孤例**。

**指挥窗口实测（`charts_demo.mp4`，十个场景的末帧）**：

| scene | 末帧亮度 | 非暗像素 | 淡出占本场景 |
|---|---|---|---|
| c01_bar | 12.0 | 0 | 2.7% |
| c02_line | 11.3 | 186 | 6.0% |
| c03_area | 11.2 | 178 | （整段低于阈值） |
| c04_slope | 11.3 | 2355 | 6.0% |
| c05_bubble | 11.1 | 0 | （同上） |
| c06_heatmap | 13.6 | 2088 | 2.7% |
| c07_rank | 11.5 | 0 | 2.7% |
| c08_volume | 11.8 | 0 | 6.0% |
| c09_sparkline | 11.1 | 0 | （同上） |
| **c10_bar_long** | **11.1** | **0** | **4.0%** |

**⇒ 十个场景全部近黑收尾，淡出占比 2.7%–6.0%，零例外。**
**而 c10 的淡出曲线是平滑渐隐**（相邻格差 375k→382k→378k→375k→360k→295k→123k→45k→0，
**1.17 秒**），不是硬切。

**⇒ 一个 10/10 一致、且是平滑渐隐的惯例，不是缺陷。**

⚠️ **注意 P27 当初也误报了这一条** —— 它自己写了"末帧肉眼几乎全黑"却仍标 FAIL，
**它把"刻意的淡出"当成了"渲染卡住"**。

### B-3：c10 的长静止 —— 判为 **真缺陷，但不是"冻结"而是"填充"**

**判据**：静止段**是不是缺陷，取决于它有没有内容**。

**指挥窗口实测（`c10_bar_long` 的 600 帧，相邻帧差 >500 的时刻）**：

```
t=0.0–1.1s   入场动画（峰值差 16,648 px）
t=4.2s        单帧跳变一次（7,999 px）
t=9.2–9.8s   淡出（峰值差 203,823 px）
```

**⇒ 中间 t=1.2s 到 9.2s 整整 8 秒，只在 4.2s 那一帧动过一次。**

而该场景的 `axisLabel` 写着 **"LONG-FORM CHART — the entrance has room to be measured"**
（长格式图表——入场有空间可被测量）—— **而入场只用 1.1 秒，那 10 秒的意图完全没兑现**。

⚠️ **P27 报的"482 帧 / 8.03s 冻结"是它用无损渲染测的，那个测法对**；
指挥窗口从成品 mp4 测时逐字节不可比（编码噪声淹没，最长相同段仅 3 帧）。
**⇒ 以 8 秒"几乎无变化"为准，不要引用 482 这个数。**

### ⚠️ 两条判定的**张力** —— 请一并想清楚

**B-2 说"淡出末帧不是缺陷"，B-3 说"8 秒静止是缺陷"。**
**它们其实是同一个问题的两面**：**这段片子靠静止填时间** ——
**每个场景 150 帧 / 2.5 秒，c10 却是 600 帧 / 10 秒**，
而它的入场 1.1 秒就结束、剩下 8 秒只能静止。

**⇒ 若 B-3 按下面改了时长，B-2 的"孤例"判据不变（十个场景仍一致）。**
